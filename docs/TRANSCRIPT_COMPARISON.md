## Coordinated implementation plan

1. Record the production composer baseline and a real hidden transcript before changing timeline behavior. Reproduce access switching with ordinary pointer clicks, including transitions back to Ask.
2. Fix the access menu's layout and response ownership. Test repeated transitions, keyboard selection, draft promotion and saved modes independently of model/reasoning selection.
3. Extend the existing pure grouping policy to known inspection/edit/command/web operations. Keep text boundaries, image previews, questions, unknown tools, unresolved errors and verified retry provenance intact. Retain stable keys and native timeline virtualization.
4. Render one compact activity header with a monochrome icon. Expand its bounded list, then expand an individual tool's recorded output or diff. Heavy content mounts only when requested.
5. Add truthful process status, compact file-change verbs, collapsed reasoning and local-reference presentation. Collapse the transcript's duplicate changed-file list, while retaining the composer review affordance.
6. Verify actual rendering, click geometry, ownership, failure/retry visibility, links, images, navigation and theme/scaling. Run focused package checks, full desktop build and exact packaged acceptance checks. Record the post-change performance measurement and deliver the candidate with screenshots.

This patch changes presentation and repairs citation replay without rewriting engine histories. It introduces no transcript migration, no copied credential store and no new context/permission semantics. “Approve for me” remains the already documented conservative local policy; it does not claim Codex's separate reviewer-agent implementation. The existing shell/edit expansion preferences apply inside an opened activity group.

## Access-menu diagnosis

The pre-change native test switched from Ask to Full, then failed to click Ask. Playwright's hit-testing log repeatedly reported that the neighboring **Approve for me** description intercepted the pointer. The generic menu item fixed every row at 28px while the access options contained multiple wrapped lines. This was a layout defect, not a missing provider model.

The menu now has its own class, content-sized rows, adequate padding and aligned check indicators. The selector also ignores stale initial reads after a local change or an authoritative access event, and captures the chat identity before saving. A response arriving after navigation cannot apply the old chat's choice to another composer. A failed load/save stays visible through the existing error notification.

## Citation replay diagnosis

The real local-engine test opened a recorded source in the browser, then submitted another request. Before the repair, the next request failed with `Invalid prompt: The messages do not match the ModelMessage[] schema.` The legacy converter copied the text part's complete metadata into SDK provider options, including its `sources` array. SDK provider namespaces must be objects.

The converter now excludes citation/presentation fields and invalid scalar/array namespaces from provider replay. It retains genuine provider object namespaces, including reasoning signatures, and leaves stored citations untouched. Two regression cases exercise the actual model-message converter; the native acceptance test continues the same conversation into an actual image read after adding and opening a source.

An early fixture also exceeded Git for Windows' nested `$GIT_DIR` path limit and therefore had no snapshots. The reproducible script uses a shorter isolated profile path. This was a QA-path limitation, not evidence that the new collapsed summary discarded file changes.

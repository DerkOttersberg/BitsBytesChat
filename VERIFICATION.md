## Complete interface and reliability patch — 9 October 2026

The accepted ten-item plan is implemented together on `main`: the reference-style sidebar and durable chat projects; a compact browser and final-tab panel closure; rendered Markdown with Source; recorded image cards; readable tool operations and verified recovery; authoritative activity ownership; actual context limits; complete local product branding; and a separate, capability-gated OpenAI image API adapter. The [feature gallery](docs/INTERFACE_PATCH_SCREENSHOTS.md) contains actual captures of the final candidate, using fictional local QA conversations.

Chat collections are separate from execution projects. The additive migration is repeatable, preserves named workspaces/worktrees, and retains conversations, drafts, queues, permissions, artifacts and execution folders when membership changes. Archive/restore are durable V2 operations. Search uses indexed literal title matching and stable timestamp/ID cursors; initial pages contain 50 summaries. A 5,201-session fixture verifies query plans without a history-wide session scan.

Context choices preserve provider output limits and existing compaction buffers. Both protocols carry the frozen request budget through queues, retries, branches and continuations. Actual compaction uses the chosen input capacity. Admission and dispatch reject a now-unsupported budget with the retained source and an actionable error. Tool recovery requires trusted operation/attempt lineage, matching output identity and a verified saved revision; ambiguous old failures remain individual. Word/PDF reads pin the requested revision, join its render job, wait with cancellation, and return successful Preparing plus a retry delay when still rendering.

Image generation uses an independently encrypted API credential, separate API billing, verified-PNG gating and capability-aware MCP discovery. Durable jobs save before submission, bound response size/time, validate/decode the PNG, publish it atomically through the existing artifact system and retain provider provenance. Stop cancels owned work. Received PNGs recover publication without another provider call; uncertain submissions and alternate job IDs cannot automatically repeat billing. Tests cover absent/revoked credentials, quota/refusal, cancellation, invalid output, duplicate identity, persistence failure and restart uncertainty. No image API key was configured, so a live paid-account generation has **not** been verified. The user's explicit **Test and enable image generation** performs one billed verification image before advertising the tool. ChatGPT OAuth model discovery cannot enable it.

# presentations

Use python-pptx for slides, shapes, images, typography, charts and theme-preserving edits. create_artifact accepts filename.pptx and slides [{title,bullets,notes}] for basic decks. Inspect the source before editing it; preserve the theme, layouts and speaker notes. Prefer restrained visual hierarchy and concise slide copy. The app uses PowerPoint to export PDF pages. Review every slide for clipping, overlap, alignment and readability, and revise before delivery.

Read [desktop-tools.md](references/desktop-tools.md) for the local creation, inspection and publication workflow.

# data analysis

Use pandas and matplotlib in run_artifact_script. Inspect schema, units, missing values, duplicates and source coverage before choosing calculations. Process the complete dataset in code; samples guide inspection but never substitute for full analysis. Check aggregates and edge cases. Save charts as PNG or SVG, results as XLSX/CSV and methods as code or Markdown; publish all relevant outputs together. Separate measurements, assumptions and inferences. Report limitations and uncertainty without inventing precision.

Read [desktop-tools.md](references/desktop-tools.md) for the local creation, inspection and publication workflow.

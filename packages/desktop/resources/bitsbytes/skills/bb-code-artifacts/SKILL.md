# code artifacts

Use normal engine file tools for source files and native terminal/version-control tools for validation. create_artifact supports a UTF-8 filename and text; run_artifact_script can generate multiple files. Publish every useful result together. For code, run appropriate focused checks rather than tests that repeat the implementation. HTML previews are isolated from Node and the privileged desktop bridge. Do not depend on file:// access or parent-window APIs. Keep external network dependencies explicit. Use chat corrections to update the same file path and refresh its existing artifact tab.

Read [desktop-tools.md](references/desktop-tools.md) for the local creation, inspection and publication workflow.

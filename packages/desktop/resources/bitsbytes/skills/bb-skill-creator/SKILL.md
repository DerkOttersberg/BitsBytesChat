# skill creator

Clarify the task, trigger, expected output and necessary templates/destinations. Draft concise SKILL.md frontmatter with name and description, followed by actionable instructions. Reuse local tools; avoid copying long tool catalogs into the skill. Keep participant personal data and credentials out of packages. save_skill creates a disabled draft with version history. Templates are optional and may be Word, Excel, PowerPoint, PDF or other files. Resources stay in the package. Test with representative sample input in a local folder before the user saves/enables the skill. Preserve exact resource references when importing/exporting; enabling is an explicit user action.

Read [desktop-tools.md](references/desktop-tools.md) for the local creation, inspection and publication workflow.

# documents

Use python-docx for paragraphs, runs, tables, headers, footers, section/page settings and precise edits. Inspect existing templates and preserve styles, runs and layout. create_artifact accepts a filename.docx, title and blocks (paragraph, heading with level, bullet, table with rows, image with path/width, pagebreak). For complex templates use run_artifact_script; never force arbitrary documents into a second-column table. Word exports the PDF preview. Review headings, pagination, whitespace, table wrapping and clipped content before final delivery.

Read [desktop-tools.md](references/desktop-tools.md) for the local creation, inspection and publication workflow.

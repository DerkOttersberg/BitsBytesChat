# Bits & Bytes Chat 0.3.3

Start **Start BitsBytesChat.cmd** or **Start BitsBytes Mobile.cmd**. Both open the same Windows application. Pair your phone through **Settings → Mobile access**; transcription settings remain under **Audio**.

- Phone microphone recording supports Pause/Resume, Cancel without upload, and Finish attaching to the original draft. Send stays separate. Progressive browser storage and resumable uploads retain recoverable recordings through interruptions.
- Phone startup defers PDF preview code. Chips and notices keep drafts compact; a second tab cannot take over active recording.
- Damaged optional state is preserved in recovery copies while valid chats/queues/artifacts remain available.
- Document publication retains immutable revisions. Historical Word/slides previews recover independently, identical Office files reuse validated previews, and failed attachment dispatch no longer leaves a chat waiting indefinitely.
- Actual app conversations were tested with GPT-5.6 Luna, including approvals, Plan/Goal, documents, long sources, queueing, steering and cancellation. A 65-minute / 47.5 MB browser recording completed full HTTPS upload and all CPU Parakeet chunks.

See [verification notes](VERIFICATION.md) for measured results and limits. Physical iPhone recording remains to be tested on the device; Dutch accuracy benchmarking is deferred. GPT-6.1 Sol still does not appear in this account's successful live model discovery. This release never selects a paid fallback automatically.
